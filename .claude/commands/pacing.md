# Pacing

Run `npm run media -- help` to confirm flags, then `npm run media -- pacing --json` with the required context. Read the selected records first. Resolve ambiguous names with the listed UUIDs. For mutations, obtain the actual actor and evidence, preview with --dry-run, then apply only the operator's intended change. Never invent records, dates or approvals.



Report the result in plain language. Every amount carries its currency. Drafts stay local. Read docs/compliance.md before interpreting checks.

Prioritise stale and missing actuals before interpreting spend variance. Expected spend is even across inclusive calendar days, not a performance forecast.
