# Draft Order

Run `npm run media -- help` to confirm flags, then `npm run media -- draft-order --json` with the required context. Read the selected records first. Resolve ambiguous names with the listed UUIDs. For mutations, obtain the actual actor and evidence, preview with --dry-run, then apply only the operator's intended change. Never invent records, dates or approvals.

Keep the generated document in drafts/. Identify open checks. Never send it, book media or treat it as signed.

Report the result in plain language. Every amount carries its currency. Drafts stay local. Read docs/compliance.md before interpreting checks.
