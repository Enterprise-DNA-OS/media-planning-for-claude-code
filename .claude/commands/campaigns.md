# Campaigns

Run `npm run media -- help` to confirm flags, then `npm run media -- campaigns --json` with the required context. Read the selected records first. Resolve ambiguous names with the listed UUIDs. For mutations, obtain the actual actor and evidence, preview with --dry-run, then apply only the operator's intended change. Never invent records, dates or approvals.
