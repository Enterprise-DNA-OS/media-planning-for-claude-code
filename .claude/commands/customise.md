# Customise

Ask which field, approval rule or workflow needs to change. Read CLAUDE.md, the current migration, CLI and the relevant command. Add a new numbered migration, never rewrite an applied migration. Preserve existing records and events. Update import mapping, documents, views and commands together. Run npm test on a temporary database. Explain and preview the change before applying a migration to real data. Never weaken claim checks to obtain approval.
